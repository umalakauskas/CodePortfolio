# Research & Project Code — Ugnius Malakauskas

Analysis code from two academic research projects completed during my studies in Economics at Vrije Universiteit Amsterdam. Full write-ups and results are described on my [CV](https://umalakauskas.github.io) and [LinkedIn](https://www.linkedin.com/in/ugnius-malakauskas-65a060343/).

Raw datasets are not included here (proprietary/large source files) — this repository contains the analysis and modelling code only.

## Contents

- **[`thesis-usd-reserves/`](./thesis-usd-reserves)** — MSc thesis: *Economic and Security Determinants of US Dollar Reserve Holdings*. Panel-data analysis across 22 reserve-holding economies (2010–2025) in R.
- **[`bright-cape-recommendation/`](./bright-cape-recommendation)** — BSc team project: recommendation-engine case study in collaboration with Bright Cape, a data analytics consultancy. My contribution was the rule-based product categorization module.
